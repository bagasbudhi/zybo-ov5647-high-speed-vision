# Tiny neural patch detector experiment

## Scope

This experiment adds a dependency-free laptop reference and a standalone synthesizable SystemVerilog inference block. It is not part of the current camera-to-HDMI block design. The network detects a bright rectangular target centered within a sliding patch. Its training examples are generated by `host/tiny_nn_detector.py`; it has not been trained on a real automotive dataset.

## Model and datapath

- Input: 24x24 grayscale window, average-pooled to 4x4 unsigned pixel values.
- Network: 16 inputs -> 8 ReLU hidden units -> 1 sigmoid score.
- Decision: score threshold 0.88. The exported fixed-point RTL compares the quantized logit against Q12 threshold 8161.
- Frame scan: laptop reference scans windows with 8-pixel stride and suppresses heavily overlapping proposals.
- FPGA block: `rtl/tiny_patch_mlp.sv` consumes the 16 pooled bytes, reuses one multiply-accumulate datapath, and returns a class result in 136 clocks. The constants in `rtl/tiny_patch_weights.svh` are generated from the checked-in trained model.

Synthesis-only utilization on XC7Z010 is 424 LUTs, 298 registers, 0 DSPs, and 0 BRAM tiles; see `tiny_nn_synthesis_utilization.txt`. The standalone RTL block is not currently connected to the OV5647/VDMA/HDMI design. The Python reference can consume a Bayer8 frame dumped over JTAG and write an annotated PNG, but live host streaming is not implemented.

## Reproduce

From the repository root in PowerShell:

```powershell
python -m unittest discover -s host -p 'test_tiny_nn_detector.py' -v
python host\tiny_nn_detector.py train --model models\tiny_patch_detector.json
python host\export_tiny_nn_weights.py --model models\tiny_patch_detector.json --output rtl\tiny_patch_weights.svh

$sim = Join-Path (Get-Location) 'build\sim_nn'
New-Item -ItemType Directory -Force $sim | Out-Null
Push-Location $sim
& 'C:\AMDDesignTools\2025.2\Vivado\bin\xvlog.bat' -sv -i ..\..\rtl ..\..\rtl\tiny_patch_mlp.sv ..\..\sim\tb_tiny_patch_mlp.sv
& 'C:\AMDDesignTools\2025.2\Vivado\bin\xelab.bat' tb_tiny_patch_mlp -s tb_tiny_patch_mlp
& 'C:\AMDDesignTools\2025.2\Vivado\bin\xsim.bat' tb_tiny_patch_mlp -runall
Pop-Location
& 'C:\AMDDesignTools\2025.2\Vivado\bin\vivado.bat' -mode batch -nojournal -nolog -source fpga\synth_tiny_nn.tcl
```

To infer on a captured raw Bayer8 frame, use `host/tiny_nn_detector.py detect <frame.raw> --phase BG --output build\capture\nn_preview.png`. This is an offline CPU run, not FPGA inference.

## Measured synthetic results

At threshold 0.88, a seeded holdout of 500 centered bright-target patches and 500 negatives produced 497 true positives, 3 false negatives, and 0 false positives. A synthetic 80x64 frame with a 16x16 target produced a 24x24 proposal with IoU 0.444. These figures describe only generated data. The model returned zero proposals on one private optical scene capture; that frame had no labeled target, so it is not an accuracy result.
