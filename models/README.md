`tiny_patch_detector.json` is the deterministic 16-8-1 MLP trained on the synthetic centered bright-rectangle patches generated by `host/tiny_nn_detector.py`. Recreate it with the `train` command in `docs/neural_detector.md`; recreate the matching RTL constants with `host/export_tiny_nn_weights.py`. It is a demonstration model, not trained or validated for automotive scenes.
